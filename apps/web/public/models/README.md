# Systems Cube model assets

The GLB and USDZ files in this folder are generated from `tools/generate_systems_cube.py` and are original Dark Ice assets. The geometry uses the Dark Ice cyan, lime, ice and navy face system, plus a live signal orbit.

Run Blender headlessly from the repository root to regenerate the assets:

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background --python tools/generate_systems_cube.py
```
